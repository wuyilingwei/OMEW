## 旁白全文

1400 天前，熟悉的地方突然安静了。

今天，OMEW 可以通过 Overture 快速部署到你自己的 Cloudflare 账户。权限清清楚楚，凭证留在你的实例。免费层足以支撑一个人运行数百到千来人的据点，先从一个小社区开始。

据点、房间、帖子和实时聊天，原来那些日常交流，又有了可以安放的地方。权限边界由社区自己决定；管理动作可见、可控，也可以在需要时暂停功能。图片、表情和分享，让空间重新有了温度。

我只是把曾经的梦之地，一点点拼凑了回来。愿这一次，成为漫长沉寂之后，仓促告别的圆满尾声。

## 发布短文

OMEW 1.0.0 回来了。

Mew 关闭 1400 天后，我把曾经的梦之地一点点拼凑回来：据点、房间、帖子、实时聊天、图片分享，以及清晰可见的权限边界。现在，任何人都可以通过 Overture 把它部署到自己的 Cloudflare 账户；应用自有的长期凭证由部署者明确授权并留在自己的 Worker 中。

它不是一座需要谁批准才能存在的城，而是一套让社区自行决定规则、保留管理权、降低滥用空间的工具。愿这次重新点亮，给那场仓促的告别留下一个圆满的尾声。
